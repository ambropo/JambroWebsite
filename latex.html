Jambro Beamer Theme

A theme for academic and policy-oriented Beamer presentations: a clean, minimalist layout with a subtle colour palette, modern typography, and a spacious design. It adds TikZ-based annotation tools — sketched arrows and handwritten-style fonts — plus pencil-style highlighting, underlining, and boxing.
GitHub repository Demo (pdf)

Jambro Notes Theme

A theme for lecture notes, working notes, and technical handouts with a light pencil-sketch aesthetic: hand-drawn underlines and boxes, sketched arrows, shaded call-outs, numbered boxes and paragraphs, and a clean sans-serif body. Built for economics and quantitative notes but useful anywhere.
